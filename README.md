# AlKhateb E-commerce store

full-stack e-commerce platform using Next.js 15, Sanity, and
PostgreSQL.

## Screenshots

![App Screenshot](https://i.ibb.co/R4ggxnmr/e-commerce.png)

## Features

- Authintication
- dashboard
- cart functionality
- Advanced Search & Filtering
- Order Management System
- Payment Integration
- Order Management System

## Tech Stack

**Client:** Next js, zustand, TailwindCSS

**Server:** postgress, Sanity

## Run Locally

Clone the project

```bash
  git clone https://github.com/DivChico/el-khateb-tech-store
```

Go to the project directory

```bash
  cd el-khateb-tech-store
```

Install dependencies

```bash
  npm install
```

Start the app

```bash
  npm run dev
```
